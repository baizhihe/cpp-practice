# 我的C++初学练习：幸运值计算器

## 📖 项目简介
这是我初学C++时，根据老师讲解和AI引导自己动手写的小程序。
用来练习：`int`变量、`cin`输入、`cout`输出、`if-else`分支判断。

## 📂 文件说明
- `lucky_原始版.cpp`：我最初写出来的版本，包含了比较复杂的嵌套结构。
- `lucky_优化版.cpp`：我查阅资料后，尝试精简代码、去除多余大括号的练习版本。

## 💡 踩坑记录（学习心得）
- 发现了 `=` 和 `==` 的区别，第一次知道 `if(a=0)` 居然会把变量强行改成0。
- 学会了在 `cout` 里写 `(1 << 2)` 这种带括号的位运算。
- 明白了 `int` 是“划拨地皮”，变量名是“贴门牌”。

## 🚀 后续计划
继续学习循环结构（for / while），准备把计算器升级成能连续玩很多次的形式。
